# CNT — Font Changer

CNT는 Chrome 기반 브라우저에서 웹사이트 폰트를 즉시 교체하고, 사이트별 글자 크기·굵기·예외 규칙을 관리하는 Manifest V3 확장 프로그램입니다.

## 4.0 핵심 변경

- **모든 일반 웹사이트에 기본 적용**: 전체 토글을 켜면 별도 사이트 등록 없이 바로 적용됩니다.
- **즉시 폰트 교체**: DOM 전체를 기다렸다가 순회하지 않고 CSS 엔진을 먼저 삽입합니다.
- **레이아웃 보호**: 기본값인 크기 100%와 굵기 400에서는 기존 `font-size`와 `font-weight`를 덮어쓰지 않습니다.
- **저부하 동적 감지**: 크기 또는 굵기를 실제로 변경할 때만 텍스트 노드를 분할 처리합니다.
- **중복 실행 제거**: 슬라이더 입력, 저장소 변경, 탭 방송이 같은 문서를 여러 번 재스캔하지 않습니다.
- **Shadow DOM 및 iframe 지원**: 열린 Shadow DOM과 하위 프레임에도 동일한 설정을 적용합니다.
- **아이콘·코드 보호**: Material Symbols, Font Awesome 계열, SVG, 코드 블록을 기본적으로 보존합니다.
- **팝업 스크롤 정상화**: 팝업 높이를 Chrome 제한에 맞추고 탭 콘텐츠만 스크롤됩니다.
- **외부 리소스 제거**: 팝업 폰트와 페이지 폰트는 저장소에 포함된 로컬 파일만 사용합니다.

## 사용 방법

1. 저장소를 ZIP으로 다운로드하고 완전히 압축 해제합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. `manifest.json`이 바로 들어 있는 폴더를 선택합니다.
6. 이미 열려 있던 웹페이지는 한 번 새로고침합니다.

로컬 `file://` 페이지는 Chrome 확장 관리 화면에서 **파일 URL에 대한 액세스 허용**을 켜야 합니다.

## 사이트 규칙

- 전체 적용이 켜져 있으면 모든 HTTP/HTTPS 사이트에 기본 스타일이 적용됩니다.
- 현재 사이트 토글을 끄면 해당 호스트만 제외됩니다.
- `example.com` 규칙은 정확한 호스트에 적용됩니다.
- `*.example.com` 규칙은 루트 도메인과 하위 도메인에 적용됩니다.
- 더 구체적인 정확한 호스트 규칙이 상위 도메인 규칙보다 우선합니다.
- 사이트별 스타일은 전체 기본 스타일에서 필요한 항목만 덮어씁니다.

## 구조

- `shared.js`: 설정 스키마 v4, 마이그레이션, 도메인 규칙, 굵기 보정
- `background.js`: 저장·캐시·중복 방송 방지·iframe 최상위 호스트 처리
- `content.js`: 즉시 CSS 적용, 선택적 텍스트 크기/굵기 엔진, Shadow DOM 감지
- `popup.js`: 실시간 미리보기, 저장 병합, 사이트 예외 및 개별 스타일 관리
- `popup.css`: 로컬 폰트 기반 단일 스크롤 팝업 UI
- `tests/`: 설정 로직 및 정적 회귀 테스트

## 검증

Node.js 20 이상에서 실행합니다.

```bash
npm run verify
```

현재 검증 항목은 다음을 포함합니다.

- 모든 JavaScript 문법 검사
- Manifest JSON 파싱
- 전체 사이트 기본 적용과 사이트별 OFF 예외
- 구버전 설정의 v4 마이그레이션
- 도메인 우선순위와 폰트 굵기 보정
- 원격 CSS·폰트 URL 미사용
- 중복 방송 방지 코드 존재 여부

## 개인정보 보호

CNT는 웹페이지 텍스트를 외부로 전송하지 않습니다. 페이지 내 폰트 적용은 브라우저 안에서만 처리되며 설정은 `chrome.storage.sync`와 빠른 초기 적용용 `chrome.storage.local` 캐시에 저장됩니다.
